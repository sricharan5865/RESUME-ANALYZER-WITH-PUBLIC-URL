Context
Problem Statement
⏱️

Time-Intensive Screening

Recruiters spend 23 hours on average reviewing resumes per hire. Manual screening of hundreds of applications creates bottlenecks and delays qualified candidates.

📧

Fragmented Email Management

Resumes arrive across multiple email accounts (Gmail, Outlook). Manually downloading, opening, and reading each attachment is repetitive and error-prone.

🔍

Keyword-Only Search Limitations

Traditional ATS systems rely on exact keyword matching, missing qualified candidates who use different terminology (e.g., "Express.js Engineer" vs. "Node.js Developer").

📋

Inconsistent Candidate Evaluation

Different recruiters evaluate candidates differently. There is no standardized scoring, no automated interview question generation, and no objective comparison framework.

Our Approach
Solution: TalentFlow Platform
A full-stack AI-powered recruitment platform that automates the entire hiring pipeline — from resume collection through candidate ranking and interview preparation.
🤖

AI-Powered Resume Parsing

Generative AI (Gemini / OpenAI / Claude / Ollama) extracts structured candidate profiles from raw PDF resumes — name, skills, experience, education, projects, seniority level.

📬

Automated Email Sourcing

Continuously monitors Gmail (IMAP) and Outlook (Microsoft Graph API) inboxes. AI categorizes each email, extracts PDF attachments, and processes resumes automatically.

🧠

Semantic Vector Search (RAG)

Converts resumes into vector embeddings. Natural language queries find semantically related candidates — "Frontend Developer" matches "React Engineer" without exact keywords.

📊

JD Matching & Interview Generation

AI scores candidates against job descriptions (0–100), identifies matching/missing skills, generates tailored HR and technical interview questions with answers.

Candidate Sourcing
Three Input Methods
Candidates enter the system through three distinct channels, each fully automated.
📤

1. Direct Upload

Recruiter manually uploads PDF resumes through the web interface. Supports single and bulk file upload. Files are stored on the server and immediately queued for AI parsing.

Drag & Drop Bulk Upload
📧

2. Gmail Integration

Connects via IMAP protocol using App Password. Background sync loop polls inbox every 30 seconds. Filters for unread emails with PDF attachments from the last 7 days. Marks processed emails as read.

IMAP Protocol Auto-Sync
📨

3. Outlook Integration

Connects via Microsoft Graph API using OAuth 2.0 Client Credentials flow. Fetches unread emails with attachments, downloads PDF content bytes, and supports sending emails directly from the platform.

Graph API OAuth 2.0

Candidate Discovery
Intelligent Search System
🔍

Advanced Tag & Keyword Search

Real-time filtering across all parsed candidate fields — skills, tags, location, seniority. Uses fuzzy matching with Dice-Sørensen coefficient for typo-tolerant search. Supports multi-filter combinations: skills + seniority + experience range.

Token Matching Fuzzy Search Multi-Filter
🧠

Semantic RAG Search

Natural language queries are converted to vector embeddings. Cosine similarity finds semantically related candidates — "Node.js Developer" matches "Express.js Backend Engineer" automatically. Keyword fallback if embedding service is offline.

Vector Embeddings Cosine Similarity Semantic

🔄 Retrieve-and-Rerank Pattern (JD Match)

The JD Match combines both search methods: Step 1 — RAG semantic search retrieves the top-K most relevant candidates. Step 2 — Each candidate is scored by the LLM against the full job description, returning a match percentage (0–100), matching skills, missing skills, and reasoning.

Candidate Scoring
Job Description Matching
📋 Paste JD Job description text
→
🧠 RAG Pre-Filter Semantic top-K
→
⚖️ LLM Scoring scoreCandidate()
→
📊 Results Ranked 0–100% match
AI Scoring Output
{
  "score": 78,
  "matchingSkills": [
    "React", "Node.js", "MongoDB"
  ],
  "missingSkills": [
    "Kubernetes", "AWS"
  ],
  "reasoning": "Strong full-stack
    profile with 4+ years of
    relevant experience..."
}
  • Semantic Understanding: The LLM understands that "Express.js Backend Engineer" is a match for "Node.js Developer" requirement
  • Experience Validation: Mathematically compares total years of experience (e.g., "6 years 4 months") against JD requirements (e.g., "5+ years")
  • Dual Scoring Modes: "Job-specific score" ranks candidates against a selected JD. "Own-category score" evaluates candidates against their own field
  • Bulk Matching: Score all candidates in the database against a single JD in one batch operation

Interview Preparation
AI Interview Question Generator
The system generates tailored interview questions based on each candidate's profile and the assigned job description.

🧑‍💼 HR & Behavioral Questions

AI generates screening questions about work culture, career goals, strengths/weaknesses — customized based on the candidate's experience level and role.

💻 Technical & Domain Questions

Questions based on the candidate's specific skills and projects. Tests depth of knowledge in their claimed areas — React hooks, database optimization, system design, etc.

📋 JD-Relevant Questions

When a job is assigned, additional questions are generated specifically targeting the job description requirements and the candidate's matching/missing skills.

Question Importance Levels
🔴 MUST ASK / VERY IMPORTANT

🟠 IMPORTANT
Significant questions about role-specific requirements
🟡 GOOD TO ASK

🔵 SCREENING

Nice-to-have questions if time permits

💡 Answers Included

Each question includes an expected answer guide for interviewers to evaluate responses objectively.

Operations
Inbox & Ingestion Tracking

  • Email preview panel — View sender, subject, date, body snippet, and attachment list directly in the app
  • Attachment-level processing — Select individual PDF attachments from emails with multiple files
  • AI category badge — Each email shows its AI classification (Resume, HR, Spam, etc.) with confidence score
  • One-click import — Process a resume attachment with a single button click
  • Auto-process toggle — Enable fully automatic processing where resume-categorized emails are imported without manual intervention
  • Email compose — Send emails directly to candidates from within the platform

  • Real-time status — Live processing status for each resume: Processing → Success / Failed / Duplicate / Cancelled
  • Source tracking — Shows whether the resume came from Manual Upload, Gmail, or Outlook
  • Error details — If parsing fails, displays the exact error message for debugging
  • Candidate linking — Successful imports show the parsed candidate name and ID for quick navigation
  • File name preservation — Original file name retained for traceability
  • Timestamp logging — Exact import time recorded for each file

Technology
Technology Stack
⚛️

Frontend

React 18 with Vite build tool. Component-based SPA with glassmorphism dark theme. Lucide React icon library. Responsive grid layouts.

🟢

Backend

Node.js + Express.js REST API server. Multer for file uploads. JWT authentication middleware. CORS-enabled for cross-origin requests.

🍃

Database

MongoDB with Mongoose ODM. Collections: Candidates, Jobs, Settings, Users, EmailLogs, IngestionLogs, ResumeChunks, ProcessedEmails.

🤖

AI & ML

5 AI providers for text generation. Vector embedding service for semantic search. Cosine similarity for candidate retrieval. JSON repair for robustness.

📧

Email Integration

ImapFlow for Gmail IMAP. Microsoft Graph API for Outlook. Mailparser for email parsing. Background polling with deduplication.

📄

Document Processing

PDF.js (pdfjs-dist) for text extraction. Python Tesseract OCR fallback for scanned/image-based PDFs. Handles all PDF formats.
